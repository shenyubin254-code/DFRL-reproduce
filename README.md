## Test
To test a trained DFRL-Mol, run

    python optimize.py --epochs_test 20 --swarm_num 20 --min_similar 0.4 --spa_model_path models/spa --dcr_model_path models/dcr --opti_object qed --use_one_mask --spa_max_length 50 --seed 0

where the parameters are:
* epochs_test: the number of epochs to test.
* swarm_num: population size.
* min_similar: the lowest allowed similarity with the lead molecule.
* spa_model_path: SPA model file path.
* dcr_model_path: DCR model file path.
* opti_object: optimization objective (qed / plogp / drd2 / qed&drd2).
* use_one_mask: use a single <|mask|> token for the masked span.
* spa_max_length: max new tokens generated by the SPA model.
* seed: random seed.
