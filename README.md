# DFRL-Mol

## Current staged reproduction

The current default is **QED, similarity 0.6, seed 0 only**, with the full
test set, 20 iterations and population size 20. This is a single-seed staged
reproduction, not a replacement for repeated-run statistics.

The full staged plan covers `qed`, `plogp` (ordinary logP), `drd2`, and
`qed&drd2` at 0.4 and 0.6, each with seed 0. Start with QED/0.6;
`bash run_group.sh OBJECTIVE SIMILARITY [--resume]` selects one group and
never automatically launches the next. Activate `dfrl39` on the server or
`dfrl-local` in local WSL first. See RUN_GUIDE.md for the ordered plan.

```bash
python -u run_benchmark.py --objectives qed --similarities 0.6 --runs 1 --seed_start 0 --output_dir benchmark_results/qed_06_seed0
# Resume the same experiment after interruption:
python -u run_benchmark.py --objectives qed --similarities 0.6 --runs 1 --seed_start 0 --output_dir benchmark_results/qed_06_seed0 --resume
```

See [the run guide](RUN_GUIDE.md) for tmux, WSL lifetime, output locations,
checkpoint limitations, and metric verification; see [the audit](AUDIT_20261018.md)
for recovered results and protocol differences. No full benchmark is started

## Test
To test a trained DFRL-Mol, run

    python optimize.py --epochs_test 20 --swarm_num 20 --min_similar 0.4 --spa_model_path models/spa --dcr_model_path models/dcr --opti_object qed --use_one_mask --spa_max_length 50 --seed 0

where the parameters are:
* epochs_test: the number of epochs to test.
* swarm_num: population size.
* min_similar: the lowest allowed similarity with the lead molecule.
* spa_model_path: SPA model file path.
* dcr_model_path: DCR model file path.
* opti_object: optimization objective (qed / plogp / drd2 / qed&drd2).
* use_one_mask: use a single <|mask|> token for the masked span.
* spa_max_length: max new tokens generated by the SPA model.
* seed: random seed.
* output_file: optional path for the CSV containing the input and optimized SMILES and their scores. If omitted,
  the results are saved to a timestamped file in `results/`.

For example, to choose the output filename:

    python optimize.py --epochs_test 20 --swarm_num 20 --min_similar 0.4 --spa_model_path models/spa --dcr_model_path models/dcr --opti_object qed --use_one_mask --spa_max_length 50 --seed 0 --output_file results/qed_optimized.csv

## Repeated paper-style benchmarks

The paper evaluates QED, logP, and DRD2 single-objective optimization, and joint QED/DRD2 optimization. Its optimization setup uses 20 iterations, a population of 20, and similarity thresholds of 0.4 and 0.6. The joint task is measured by the fraction of molecules with QED > 0.6 and DRD2 > 0.5 (Figure 2). This repository's `optimize.py` supports the joint QED/DRD2 optimization task; use the quoted objective because `&` has a special meaning in shells.

Run five seeds for the joint task at both similarity thresholds:

    python run_benchmark.py --objectives 'qed&drd2' --similarities 0.4 0.6 --runs 5 --seed_start 0

Run all supported optimization tasks:

    python run_benchmark.py --objectives qed plogp drd2 'qed&drd2' --similarities 0.4 0.6 --runs 5 --seed_start 0

Runs are executed sequentially, which avoids loading multiple copies of the models onto the GPU. Results are written under a timestamped `benchmark_results/` directory by default:

* `runs/`: molecule-level CSV from each seed.
* `all_molecule_results.csv`: molecule-level results combined across seeds.
* `per_run_metrics.csv`: paper-style metrics for each seed.
* `summary.csv`: mean and standard deviation of each metric across seeds. Threshold success metrics are reported as percentages.

For a single-objective run, the script reports the paper's QED and DRD2 threshold rates or mean logP improvement, as applicable. For the joint task, it reports the QED/DRD2 success rate. The seed-level mean and standard deviation quantify run-to-run variability; they are not directly comparable to a paper value unless the paper reports the same repeated-run protocol. The article's de novo multi-objective generation benchmarks (GSK3β/JNK3 and GSK3β/JNK3/QED/SA) are not implemented here because this repository does not include those target oracles and scaffold-generation setup.

Paper: [DFRL-Mol: a dual-stage framework of reinforcement learning for multi-scenario molecule optimization](https://doi.org/10.1093/bib/bbag493).
